# GitHub 源码发布

本项目使用账号 `zz77vv` 下独立私有仓库 `cxbot`，默认分支 `main`。
业务名称和服务器目录一致；与 JZBot、JZBot V2 的仓库、凭据和生产流程分开维护。

正式源码位于 `telegram_bot_v2/`；本地独立脱敏镜像位于工作区 `.github-publish/`。
首次发布从源码/测试/文档允许清单创建全新的 Git 历史，不导入旧单文件或其他项目历史。
后续同步必须核对远程 main 与本地发布历史，不使用 force push，不覆盖独立远程修改。

发布包括模块源码、测试、固定依赖、空值配置示例、部署与维护文档。
禁止上传真实环境配置、Session、任何数据库、缓存、日志、服务器连接信息、SSH 已知主机和虚拟环境。
测试报告保留实际用例数、结果和耗时；机器名等本地环境标识在发布镜像中脱敏。

发布前先检查编译、全部模块导入和适用的完整离线测试，再扫描允许清单和待提交历史。
扫描原源码凭据时只做内存匹配，不打印凭据。
发布后核对远端提交 SHA、仓库私有性与文件内容。

GitHub 更新仅代表源码已发布。服务器 `/root/cxbot` 已准备源码和独立运行环境，仍需要本地私有配置与新账号交互登录。
不使用旧数据库；首次运行初始化新库。发布本身不会启动 polling、签到、查询或修改其他服务器项目。

此前 AUDIT.md、TEST_REPORT.md、release_audit.json 为初始构建阶段记录，其中“未配置 GitHub”“未连接服务器”等描述反映当时的验收边界；当前发布与服务器准备以本说明及实际提交/运行记录为准。
