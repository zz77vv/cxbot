# 修改清单

- 独立目录交付，旧源码 SHA256 只读核对；未复制凭据、数据库或 Session。
- 显式组装服务，配置、目标规则、模型、客户端、命令、业务、Repository、迁移和生命周期分别维护。
- 单一客户端所有者；数字 Session 发现、非交互授权检测、有限连接退避、每账号锁、持久化 FloodWait、真实状态和关闭处理。
- 签到计划持久化、启动去重；最后尝试与确认成功分开；失败/超时不写成功；手动并发和自动调度共享间隔检查。
- 保留三个目标原指令及正则；余额零值和超时、解析变化、不可用明确分类；不记录原始余额回复。
- JR 两种语法统一路由；基于更新 ID 持久去重，同键有引用计数的异步锁；余额实时排序、北京时间日限额、未知任务额度预留。
- 发送/购买/导出前写入意图；不自动重放收费动作，未知状态不换号；重启恢复元信息并通知管理员。
- 查询成功、会员观测、用量、缓存原子提交；保存结果但未交付时，超过 TTL 仍不重新购买。
- 原 OCR 图片预处理和 ddddocr 概率结构兼容保留，单线程、有界等待、低置信度/忙/失败分别返回。第三方安全验证暂停人工处理，删除远程自动验证点击和重发流程。
- 文件原名展示、固定安全磁盘名、范围限制、单次导出、文件关联、分页回退、200 页及重复页限制。
- 消息按 UTF-16 和 HTML 转义后的长度分段；长行和 emoji 不超限；JR 结果按纯文本发送。
- 清理检查缓存、在途任务和交付引用；目录外路径、符号链接不删除；遗留无主文件过 TTL 后清理。
- 交付意图和分段进度持久化；发送不明确不自动重发；提供停止服务后的人工核实和保存结果交付工具。
- 广告命令、配置、内容、轮换、循环、调度和状态完全未迁入运行源码；静态和命令注册测试覆盖删除结果。
- SQLite backup、未知结构拒绝、事务取消回滚、操作系统进程互斥、轮转脱敏日志与后台异常收割。

行为调整依据：手动签到也执行 24 小时间隔，依据本次明确约束；未知文本不直接作为成功，依据状态正确性要求；安全验证人工处理，依据本次禁止绕过访问控制要求；未知交付需核实，依据防重复发送要求。未增添数据源、查询类型、批量采集、充值或普通用户业务。
